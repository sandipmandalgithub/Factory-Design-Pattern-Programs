# Factory Design Pattern Programs

This repository contains Java programs demonstrating the **Factory Design Pattern** in Object-Oriented Programming (OOP).

The programs demonstrate how object creation can be handled through a factory instead of directly creating objects in the client code.

## 📚 Concepts Covered

* Factory Design Pattern
* Object Creation
* Interfaces
* Abstraction
* Polymorphism
* Loose Coupling
* Encapsulation
* Separation of Object Creation Logic

## 🏗️ Factory Design Pattern

The Factory Design Pattern provides an approach for creating objects without exposing the object creation logic directly to the client.

A factory class is responsible for deciding which object should be created based on the given input.

1. Clone or download this repository.
